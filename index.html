maim

maim is an AI-powered bot that turns daily crypto news into memes and short videos, published to the owner's own social media accounts (X, Instagram, TikTok, YouTube).

TikTok integration: uses TikTok's Content Posting API so the account owner can publish their own generated videos to their own TikTok account. No third-party user data is collected.
